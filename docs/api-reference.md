## ELF Section Formats

### `.sentinel` — Syscall Policy Array

Generated by the LLVM pass. Contains an array of policy entries describing every syscall site in the binary.

**Entry Layout (24 bytes each):**

```c
struct sentinel_policy_entry {
    uint64_t site_addr;   // Absolute address of syscall instruction
    uint64_t func_addr;   // Absolute address of enclosing function
    int64_t  syscall_nr;  // Encoded syscall number (see Policy Value Encoding)
};
```

**`syscall_nr` field encoding:**

| Value | Meaning |
|-------|---------|
| `0` | Unspecified — allow any syscall number at this site |
| `N > 0` | Expected syscall number is `N - 1` (e.g., `2` means `write` / NR=1) |

The loader transforms this to the BPF policy value format (see [Policy Value Encoding](#policy-value-encoding)).

### `.sentinel_cfi` — CFI Caller-Range Metadata

Generated by the LLVM pass. Contains `{site, function}` pairs that the loader uses to build caller-validation ranges.

**Entry Layout (16 bytes each):**

```c
struct sentinel_cfi_entry {
    void *site_addr;      // Absolute address of syscall site
    void *func_addr;      // Absolute address of enclosing function
};
```

The loader looks up each `func_addr` in the ELF symbol table to get `st_size`, then installs `cfi_policy[offset] = {func_start_offset, func_start_offset + st_size}`.

### `.sentinel_imports` — External Function List

Generated by the LLVM pass. A blob of null-terminated C strings listing every external function the binary references (calls or takes the address of).

**Format:**

```
"fopen\0printf\0write\0fclose\0exit\0"
```

The loader parses this by scanning for `\0` delimiters and uses each name as a seed for call-graph BFS through libc.

### `.signature` — Ed25519 Signature

64 bytes containing the Ed25519 signature over `SHA-256(.text || .sentinel || .sentinel_cfi || .sentinel_imports)`.

Written by `sign_tool`. Verified by `loader` using the public key from the Linux Kernel Keyring.

## Shared Data Structures

Defined in `src/common/sentinel_shared.h`. This header is the **single source of truth** for all types shared between BPF and userspace.

### Type Bridging

```c
#ifdef __BPF__
  #define S_U8  u8       // Kernel types
  #define S_U32 u32
  #define S_U64 u64
#else
  #define S_U8  uint8_t  // Userspace types
  #define S_U32 uint32_t
  #define S_U64 uint64_t
#endif
```

### Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MODULE_MAIN` | `1` | Module ID for the main binary |
| `MODULE_LIBC` | `2` | Module ID for libc |
| `MODULE_DYNAMIC_BASE` | `3` | First dynamically-assigned module ID |
| `EVENT_ALLOW` | `0` | Audit: syscall allowed |
| `EVENT_BLOCK` | `1` | Audit: syscall blocked |
| `EVENT_CFI_OK` | `2` | Audit: CFI check passed |
| `EVENT_CFI_FAIL` | `3` | Audit: CFI check failed |
| `EVENT_NR_MISMATCH` | `4` | Audit: syscall number mismatch |
| `EVENT_FORK_TRACK` | `5` | Audit: child auto-enrolled |
| `POLICY_FLAG_CHECK_NR` | `1ULL << 32` | Policy: validate syscall NR |

### `struct audit_event` (48 bytes)

```c
struct audit_event {
    S_U64 timestamp_ns;    // bpf_ktime_get_ns()
    S_U32 tgid;            // Thread Group ID (process)
    S_U32 tid;             // Thread ID
    S_U64 syscall_rip;     // Absolute address of syscall instruction
    S_U64 offset;          // Module-relative offset
    S_U32 module_id;       // Which module (1=main, 2=libc, ...)
    S_U32 syscall_nr;      // Actual syscall number from fentry hook
    S_U8  action;          // EVENT_ALLOW / EVENT_BLOCK / ...
    S_U8  _pad[7];         // Alignment padding
};
```

### `struct vma_key` (12 bytes, packed)

```c
struct vma_key {
    S_U32 prefixlen;       // LPM prefix length (typically 44 for 1MB blocks)
    S_U64 addr;            // Big-endian address for LPM matching
} __attribute__((packed));
```

### `struct vma_value` (12 bytes, packed)

```c
struct vma_value {
    S_U32 module_id;       // Module this VMA belongs to
    S_U64 base_addr;       // Base address for offset computation
} __attribute__((packed));
```

### `struct cfi_range` (16 bytes)

```c
struct cfi_range {
    S_U64 start;           // Valid caller start offset
    S_U64 end;             // Valid caller end offset
};
```

## BPF Map Schemas

### `target_pid_map` — Process Tracking

| Property | Value |
|----------|-------|
| Type | `BPF_MAP_TYPE_HASH` |
| Max entries | 64 |
| Key | `u32` (TGID) |
| Value | `u32` (always 1) |

Tracks which processes are under Sentinel enforcement. Auto-populated for child processes via fork tracking.

### `vma_map` — Virtual Memory Area Lookup

| Property | Value |
|----------|-------|
| Type | `BPF_MAP_TYPE_LPM_TRIE` |
| Max entries | 512 |
| Flags | `BPF_F_NO_PREALLOC` |
| Key | `struct vma_key` (12 bytes) |
| Value | `struct vma_value` (12 bytes) |

Maps address ranges to module IDs. Uses 1MB blocks (20-bit granularity, 44-bit prefix) with big-endian keys for longest-prefix matching.

### `policy_registry` — Module Policy Index

| Property | Value |
|----------|-------|
| Type | `BPF_MAP_TYPE_ARRAY_OF_MAPS` |
| Max entries | 64 |
| Key | `u32` (module_id) |
| Value | fd to `inner_policy_map` |

Each slot holds a file descriptor to a per-module hash map containing that module's whitelisted offsets.

### `inner_policy` — Per-Module Offset Whitelist

| Property | Value |
|----------|-------|
| Type | `BPF_MAP_TYPE_HASH` |
| Max entries | 4096 |
| Key | `u64` (module-relative offset) |
| Value | `u64` (policy value) |

### `cfi_policy` — Deep CFI Ranges

| Property | Value |
|----------|-------|
| Type | `BPF_MAP_TYPE_HASH` |
| Max entries | 1024 |
| Key | `u64` (syscall offset) |
| Value | `struct cfi_range` (16 bytes) |

### `audit_ringbuf` — Event Ring Buffer

| Property | Value |
|----------|-------|
| Type | `BPF_MAP_TYPE_RINGBUF` |
| Size | 256 KB |
| Event | `struct audit_event` (48 bytes) |

## Policy Value Encoding

The `u64` policy value stored in `inner_policy` maps uses bit-packing:

```
Bit 63                    Bit 32  Bit 31                    Bit 0
┌─────────────────────────┬──────┬─────────────────────────────────┐
│       (reserved)        │CHECK │     Expected Syscall NR         │
│                         │  NR  │     (if CHECK_NR is set)        │
└─────────────────────────┴──────┴─────────────────────────────────┘
```

| Value | Meaning |
|-------|---------|
| `1` | Allow — any syscall number accepted at this offset |
| `(1ULL << 32) \| nr` | Allow only if actual syscall number == `nr` |

## CLI Reference: sentinel-loader

```
Usage: sentinel-loader [options] <binary> [args...]

Options:
  --help, -h       Show help message
  --version, -v    Show version (Sentinel-CC vX.Y.Z)
  --audit          Enable real-time audit event printing

Examples:
  sudo sentinel-loader ./victim
  sudo sentinel-loader --audit ./victim_phase2
```

**Exit Codes:**

| Code | Meaning |
|------|---------|
| 0 | Child exited normally |
| 1 | Fatal error (signature failure, missing key, BPF load failure) |
| 128+N | Loader killed by signal N |
| Child's exit code | Propagated from the monitored binary |

**Environment Requirements:**
- Must run as **root** (for BPF and ptrace)
- Public key must be in session keyring: `keyctl add user sentinel:pubkey "$(cat pub.pem)" @s`
- Kernel must have BTF support (`/sys/kernel/btf/vmlinux`)

**Audit Output Format:**

```
[Audit] ALLOW PID=<tgid> TID=<tid> SYS=<nr> RIP=0x<addr> Off=0x<offset> Mod=<id>
[Audit] BLOCK PID=<tgid> TID=<tid> SYS=<nr> RIP=0x<addr> Off=0x<offset> Mod=<id>
[Audit] CFI_OK PID=<tgid> TID=<tid> SYS=<nr> RIP=0x<addr> Off=0x<offset> Mod=<id>
[Audit] CFI_FAIL PID=<tgid> TID=<tid> SYS=<nr> RIP=0x<addr> Off=0x<offset> Mod=<id>
[Audit] NR_MISMATCH PID=<tgid> TID=<tid> SYS=<nr> RIP=0x<addr> Off=0x<offset> Mod=<id>
[Audit] FORK_TRACK PID=<parent_tgid> TID=<child_tgid>
```

## CLI Reference: sentinel-sign

```
Usage: sentinel-sign [options] <binary> <private.pem>

Options:
  --help, -h       Show help message
  --version, -v    Show version

Examples:
  ./sentinel-sign victim priv.pem
  sentinel-sign /usr/local/bin/myapp /etc/sentinel/priv.pem
```

**What it signs:** `SHA-256(.text || .sentinel || .sentinel_cfi || .sentinel_imports)`

**Signature algorithm:** Ed25519 (64-byte signature)

**Output:** Writes the signature into the binary's `.signature` section in-place.

## Key Management

### Key Generation

```bash
make keys    # Creates priv.pem + pub.pem (Ed25519)
```

### Keyring Setup

```bash
# Load public key into session keyring (required before running loader)
sudo keyctl add user sentinel:pubkey "$(cat pub.pem)" @s
```

### Key Rotation

```bash
sudo make key-rotate
```

This:
1. Computes SHA-256 fingerprint of current `pub.pem`
2. Appends fingerprint to `/etc/sentinel/revoked_keys`
3. Generates new Ed25519 keypair
4. Re-signs all binaries (victims + attacks)
5. Updates the keyring

### Revocation File Format

`/etc/sentinel/revoked_keys` — one SHA-256 fingerprint per line:

```
# Revoked on 2026-03-01 — key compromise
a1b2c3d4e5f6...  (64 hex characters)
# Revoked on 2026-03-05 — scheduled rotation
f6e5d4c3b2a1...
```

Lines starting with `#` are treated as comments.
